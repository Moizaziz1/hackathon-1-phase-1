# ROS 2 Architecture Diagrams

## ROS 2 Communication Architecture

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Publisher     │    │                 │    │   Subscriber    │
│   Node A        │◄───┤   ROS 2         │───►│   Node B        │
│                 │    │   Middleware    │    │                 │
│  /topic_name    │    │   (DDS)         │    │  /topic_name    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │                       │
         ▼                       ▼                       ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Application   │    │   Network       │    │   Application   │
│   Layer         │    │   Layer         │    │   Layer         │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```
